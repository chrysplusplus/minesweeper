# Minesweeper

Minesweeper for your terminal.

## Installation (Windows)

1. Install the prerequisitve Python curses library with:

    `pip install windows-curses`

1. Clone the repository, or download the latest ZIP archive from the
   [releases page](https://github.com/chrysplusplus/minesweeper/releases) and
   extract the archive.

1. Open the repository folder in the Command Prompt (or Powershell, if you
   prefer).

1. Run with `python minesweeper.py`

## Installation (Unix)

1. Clone the repository, or download the latest ZIP archive from the
   [releases page](https://github.com/chrysplusplus/minesweeper/releases) and
   extract the archive.

1. Open the repository directory in your terminal

1. Run program with `./minesweeper`
